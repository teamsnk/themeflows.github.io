HELP CENTER

Frequently asked questions.

Is ThemeFlow a live marketplace? ＋

This package is a static front-end prototype. It showcases the intended marketplace experience but has no live product database, seller accounts, or order management.

Does the theme purchase button charge me? ＋

No. The purchase action only displays a demo notice. No payment processor is connected and no money is collected.

Does the support chat use AI or a live agent? ＋

The chat is a local demo with preset responses. Messages are not sent to a server, live agent, or AI service.

Can I use this site on GitHub Pages? ＋

Yes. The site uses static HTML, CSS, and JavaScript. Upload the extracted files with index.html at the repository root, then enable GitHub Pages in repository Settings.

How do I make it production-ready? ＋

Connect authentication, a product database, secure checkout, seller moderation, file delivery, transactional email, and real support infrastructure before accepting customers.
